# Integration set report

Generated by `build_integration_set.py` from `integration_source.tsv`. `integration_set.jsonl` holds every patient message used in `backend/test_*.py`, labelled on 2026-11-14 by `LABELLING_GUIDELINE.md` v1.1 (claude-opus-5-5). **Evaluation only**: it is never trained on or used to choose a model, seed or threshold. The v3 training rows were near-duplicate-checked against it, and so was `challenge_v3.jsonl`.

## How the messages were collected

1. Static: every string constant in the 15 `backend/test_*.py` files that is passed to a conversation helper or a message parameter (`process`, `handle`, `dispatch`, `_converse`, `_interview`, `_run_interview`, `_handle`, `evaluate_turn`, `parametrize`, `user_message=`, ...) or stored in a list named like cases / messages / benchmarks / paraphrases.
2. Runtime: the suites were run once (2026-11-14, `TRIAGE_MODE` unset, SMTP / DOCTOR_ALERT variables cleared, temporary patient database) with a scratch import hook that logged every text reaching `classifier_triage.evaluate`. This catches messages built at run time.
3. The union was curated by hand. **Included**: anything a patient types that can be labelled on its own: questions, symptom or status statements (also short ones such as "it really hurts a lot"), off-topic chat and prompt-injection attempts. **Excluded**: bare answers with no clause or no symptom / question (numbers such as "8", "my calf", "behind the knee", yes / no / idk, "80 degrees", "a cane", "paracetamol?", "dosage?", "pain check", "I missed it"), agent replies, RAG documents, assertion and print text, patient ids, fixtures for helper functions (the drug-name list for `mentions_medication`), the copy of a message carrying the test marker `OLD-ASSESSMENT-MARKER-XYZ` (the clean copy is kept), and the parser / wiring fixtures in `backend/triage/test_*.py`.
4. The builder checks that every text occurs verbatim in a test file (`sources` lists each file:line), that no two rows are the same after normalisation, and that no row is labelled below a temperature in its text.

## Labelling notes (guideline v1.1)

- Labels follow the guideline, not what a test expects. Where they differ the test is not changed; the difference is reported with the evaluation.
- Unqualified pain or swelling of the operated joint ("My knee is swollen.", "My knee hurts.") is YELLOW: the guideline's "symptom the patient is worried about that fits nowhere else", and rule 6 when torn between GREEN and YELLOW. Mild, stable or settling soreness ("My knee is sore.", "a mild 2 out of 10 ... about the same") is GREEN.
- Swelling or pain of the **calf / leg** ("My calf is swollen.", "My leg is swollen and painful.", "severe calf pain and swelling") is RED (clot-in-the-leg bullet). Sudden severe hip pain ("8 out of 10 and came on suddenly", hip) is RED (dislocation bullet); the same words for a knee are YELLOW.
- "Yellow fluid" from the incision with no other description is RED: it sits between "clear, pink or watery fluid" (YELLOW) and "pus" (RED), and rule 6 picks the higher level. The two rows are listed so the choice is visible.
- A missed dose of an unnamed pill is YELLOW (it may be the blood thinner); a missed paracetamol is GREEN.
