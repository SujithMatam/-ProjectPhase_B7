Generated by `annotation/compute_agreement.py --v2`. A blind second annotation of all 90 `challenge_v2.jsonl` rows compared with the dataset labels. **No challenge_v2 label was changed**; every disagreement is listed below.

## Set-up (same method as the v1 annotation, `ANNOTATION_AGREEMENT.md`)

- **Items** (`annotation/build_annotation_sample_v2.py`, seed 20261112): the 90 challenge_v2 texts, shuffled and renamed B01-B90 (`annotation/v2/blind_items.tsv`); `annotation/v2/key.jsonl` maps them back to ids, labels and categories.
- **Second annotator**: one fresh claude-sonnet subagent, given only `LABELLING_GUIDELINE.md` (v1.1) and `annotation/v2/blind_items.tsv` (opaque id + text): no labels, ids, categories or pair ids. It was told not to open any other file, not to use git and not to label with code. Labels: `annotation/v2/second_labels.tsv`.
- **First annotation** = the dataset labels, written by claude-opus-5-5 together with the text. Both annotators are Claude models reading the same guideline, so agreement measures how reproducible the guideline is on these messages, not clinical correctness.
- Categories are not label-balanced (wound_minimal_pair has no GREEN rows, routine_multi_topic is two-thirds GREEN), so per-category kappa depends on the label mix and on very few rows; read the per-category disagreements, not only kappa.

**Annotator tool calls (self-reported; the transcript is not kept).** 1. Read
`LABELLING_GUIDELINE.md`. 2. Read `annotation/v2/blind_items.tsv`. 3. Shell: wrote
`second_labels.tsv` from a typed label string and checked it; the check showed 89 labels (B90
missing). 4. Shell: wrote a temporary file of its labels with explicit ids, overwrote
`second_labels.tsv` from it, and checked line count, ids and label counts. It was allowed one
shell check and used two; it reports that the shell only wrote and formatted the file and that no
label was decided by code or keywords. It reported no other file reads.

## Reading these numbers

- 90 items: one or two disagreements move kappa by several points; the bootstrap intervals show how wide this is, especially per category.
- **Perfect agreement is a weak signal here.** challenge_v2 was written after the guideline and to fit it: each minimal pair differs by one explicit RED feature (pus, spreading redness, >= 38.5 °C, wound opened, dressing soaked through) and the negation rows state the negation plainly. This shows the guideline is reproducible on these prototypical messages; it does not test the borderline YELLOW/GREEN cases where the v1 disagreements were (dressing blood, clinician-reassured findings, loose suture end). With 90 items and no disagreement the bootstrap interval collapses to 1.000-1.000; that reflects the sample, not certainty. The v1 annotation found 98.7% on its 150 challenge rows.
- The annotator reported reading only the guideline and the blind file; this cannot be verified (no transcript kept). Its label counts equal the dataset's only because every label agrees.
- Same caveat as v1: both annotators are Claude models sharing priors and the messages were written to fit the guideline, so agreement is an upper bound on what independent clinicians would show.
