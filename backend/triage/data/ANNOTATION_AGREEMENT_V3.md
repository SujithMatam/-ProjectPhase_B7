# Annotation agreement: challenge_v3 and the integration set

Generated by `annotation/compute_agreement_v3.py`. A blind second annotation of all 91 `challenge_v3.jsonl` rows and all 272 `integration_set.jsonl` rows, compared with the dataset labels. **No label was changed**; every disagreement is listed below.

## Set-up (same method as `ANNOTATION_AGREEMENT_V2.md`)

- **Items** (`annotation/build_annotation_sample_v3.py`, seed 20261114): the 363 texts of both sets pooled, shuffled and renamed C001-C363 (`annotation/v3/blind_items.tsv`), so the annotator could not tell the sets apart; `annotation/v3/key.jsonl` maps them back.
- **Second annotator**: one fresh claude-sonnet subagent, given only `LABELLING_GUIDELINE.md` (v1.1) and the blind file. It was told not to open any other file, not to use git and not to label with code. Labels: `annotation/v3/second_labels.tsv`.
- **First annotation** = the dataset labels (claude-opus-5-5). Both annotators are Claude models reading the same guideline: agreement measures how reproducible the guideline is on these messages, not clinical correctness.

**Annotator tool calls (self-reported; the transcript is not kept).** 1. Read
`LABELLING_GUIDELINE.md` in full. 2. Read `annotation/v3/blind_items.tsv` in full. 3. Shell: wrote
`second_labels.tsv` from a hand-typed string of R/Y/G letters (the shell only numbered them into
ids); the string was mistyped and gave 390 lines, so the file was overwritten. 4. Shell: the same
command with the letters re-entered in blocks of ten (363 ids), then `cut | sort | uniq -c` for the
counts. 5. Two spot-check greps of about 25 ids to confirm labels sat on the right ids. It reports
no other file reads and no git. Reported counts: GREEN 203, YELLOW 104, RED 56.
