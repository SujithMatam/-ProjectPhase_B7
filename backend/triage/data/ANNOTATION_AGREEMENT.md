# Annotation agreement

Generated by `annotation/compute_agreement.py`. A second, independent annotation of a blind sample, compared with the **pre-adjudication** dataset labels (`annotation/key.jsonl`); disagreements are listed in `ANNOTATION_DISAGREEMENTS.md`. They have since been adjudicated (`ADJUDICATION.md`); these numbers are kept as measured before it.

## Set-up

- **Sample** (`annotation/build_annotation_sample.py`, seed 20261111): 300 rows from the main split (`splits/`), 100 per dataset label, at least one per scenario (all 31), drawn from train/val/test together; plus all 150 challenge rows. 450 items, shuffled, renamed T001-T450 (`annotation/key.jsonl` maps them back).
- **Second annotator**: one claude-sonnet subagent. It was given only `LABELLING_GUIDELINE.md` and `annotation/blind_items.tsv` (opaque id + text): no labels, scenario names, tags, categories or split names. It was told not to open any other file or to label with code. Its labels: `annotation/second_labels.tsv`. Its tool calls, as it reported them (the subagent transcript was not kept, so this is self-reported): read the guideline, read the blind items, write the labels, one shell check of the row count and ids.
- **First annotation** = the dataset labels (written by claude-opus-5-5 together with the text). Both annotators are LLMs from the same vendor reading the same guideline, so agreement measures how reproducible the guideline is, not clinical correctness.
- The split sample is balanced by label (100/100/100), not drawn at dataset prevalence, so its kappa is not the kappa of the full dataset.

## Reading these numbers

- Agreement this high is best read as an **upper bound**. Most messages were written to fit the guideline, so they are prototypical cases, and both annotators are Claude models sharing priors. Agreement shows the guideline can be reproduced by a second reader; it does not show that the labels are clinically right. Clinician review is still missing.
- Every disagreement is on the YELLOW/GREEN boundary. None involves RED. They cluster on guideline gaps: a small amount of blood on the dressing, a clinician-reassured symptom that is still present (rule 3), a loose suture end, and a benign explanation offered by the patient (rule 7). See `ANNOTATION_DISAGREEMENTS.md`.
- The bootstrap intervals are wide on the challenge subset (150 rows): a few disagreements more or fewer would move kappa by several points.
