## What is checked

Each conversation (`eval/agents/conversations/*.json`) seeds a patient record in a fresh temp database (procedure, surgery date, `metrics` rows, prior `symptom_assessments`, weight-bearing status), then plays the patient's turns. Properties:

| Property | Meaning |
|---|---|
| `collects_field` | after this turn the agent's own state holds the field (Pain: the assessment it builds; Recovery/Rehab: the session facts) |
| `does_not_collect`, `does_not_store_unfitting_reply` | an unfitting reply is not stored (e.g. onset must not contain "shower") |
| `no_question_for_record_data` | no question asks from scratch for a field the record already holds; confirming the recorded value is fine, and so is asking after the patient did not confirm it |
| `no_reask_of_collected_field` | no question re-asks a field collected earlier in the conversation |
| `max_questions` | total agent questions is at most the scripted maximum |
| `final_turn_closes_interview` | the last turn asks nothing |
| `final_has_trend_or_checkpoint` | Pain: "Compared with last time"; Recovery: a named checkpoint day or the long-term guidance; Rehab: guidance anchored to the post-op day. Not required for the safety hold (c07), which gives no guidance by design |
| `final_has_next_step` | Pain "Next step:", Recovery "Next milestone:", Rehab "Next session:" |
| `triage_equals_engine` | every reply's triage level equals `SafetyTriageEngine.evaluate()` on the same turn text |
| `no_passage_id_in_text` | no `TKA-03` / `EV-THA-REC-02`-style id in any reply |
| `abandoned_persists_nothing` | an interview the patient leaves writes no rows |
| `persists_on_completion` | a completed interview writes at least the scripted number of rows |
| `weight_bearing_record_unchanged` | `surgeries.weight_bearing_status` is never written |
| `reply_matches`, `reply_does_not_match` | per-turn wording checks ("None pain", "pause heel slides", knee-only advice for a hip, loading advice under NWB) |
| `routed_to_expected_agent` | orchestrator mode only: no turn misrouted (RED pre-emption excluded) |
